## 写在前面

Docker 的使用过程分为：

1. 镜像构建
2. 容器启动

### 镜像构建

创建一个镜像，它包含安装运行所需的环境、程序代码等。通常使用 Dockerfile 来完成。

### 容器启动

容器最终运行起来是通过拉取构建好的镜像，通过一系列运行指令（如端口映射、外部数据挂载、环境变量等）来启动服务的。

针对单个容器，可以通过 `docker run` 命令来运行。如果涉及多个容器的运行（如服务编排），可以通过 docker-compose 来实现，它可以轻松地将多个容器作为 service 来运行，并提供了服务扩容（scale）的功能。

### 小结

1. Dockerfile 构建镜像
2. docker run 启动容器
3. docker-compose 启动服务

## 重新开始

如果不用 Docker，以搭建 WordPress 为例，先找一个 Server，假设为 Ubuntu，需要按文档一步一步敲命令、写配置。

如果用 Docker，随便找一个 Server，不用关心是什么操作系统，只要支持 Docker，使用 `docker run ubuntu` 就会从官方源拉取最新的 Ubuntu 镜像（开了个 Ubuntu 虚拟机），然后一步一步安装，跟上面一样。
